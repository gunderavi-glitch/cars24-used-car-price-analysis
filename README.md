# Cars24 Used Car Price Analysis

## Project Overview

This project analyzes used car data from the Cars24 marketplace using Python. The project focuses on data collection, data cleaning, price analysis, and visualization to understand used car pricing patterns.

## Objectives

- Collect used car data from Cars24
- Clean and prepare the dataset
- Analyze car prices and related factors
- Identify patterns in used car pricing
- Create meaningful visualizations
- Generate business-oriented insights

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- BeautifulSoup
- Requests
- Jupyter Notebook

## Data Processing

The project includes:

- Data collection
- Missing value checking
- Duplicate checking
- Data type conversion
- Data cleaning and transformation
- Outlier handling using the IQR method
- Numerical and categorical analysis
- Data visualization

## Project Files

- `Cars24_Used_Car_Price_Analysis.ipynb` – Complete Python analysis notebook
- `cars24_clean_data.xls` – Cleaned Cars24 dataset
- `Cars24_Used_Car_Price_Analysis_ppt.pptx` – Project presentation

## Key Analysis

The project analyzes factors such as:

- Used car prices
- Car brands and models
- Fuel types
- Transmission types
- Kilometers driven
- Location
- Price-related patterns

## Conclusion

The project demonstrates how Python can be used to collect, clean, analyze, and visualize real-world used car data to generate meaningful insights.
